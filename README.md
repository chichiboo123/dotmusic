# 🎵 Dot Music

> **점을 찍으면, 음악이 됩니다.**
> 이미지·영상·웹캠의 움직임을 격자(Grid) 위의 점으로 바꾸고, 그 점을 소리로 연주하는 브라우저 기반 비주얼 시퀀서입니다.

🔗 **바로 사용하기 → [dotmusic.chichiboo.link](https://dotmusic.chichiboo.link)**

---

## 💡 영감을 준 분들께 (Inspiration & Respect)

> **'Dot Music'은 인스타그램 크리에이터 [@nsmrnoak](https://instagram.com/nsmrnoak) & [@lolalevient](https://instagram.com/lolalevient) 의 영상에서 영감을 받아 제작하였습니다.**

두 크리에이터가 보여준 **"점과 격자가 소리가 되는 장면"** 은 이 프로젝트의 출발점이었습니다.
화면 위를 지나가는 스캔 라인, 점이 켜질 때마다 울리는 맑은 음, 그리고 움직임이 그대로 리듬이 되는 감각 —
그 아름다운 아이디어를 처음 보았을 때의 설렘이 없었다면 이 도구는 존재하지 않았을 것입니다.

이 프로젝트는 두 분의 작업을 복제하거나 대체하기 위한 것이 아니라,
**그 영감을 교실에서 아이들이 직접 만져볼 수 있는 형태로 옮기기 위한 교육용 재해석**입니다.
원본 영상의 창작자분들께 깊은 존경과 감사를 표합니다. 🙏

> 앱 내 **도움말(Help) 모달 하단**에도 이 출처 표기가 상시 노출되어 있습니다.
> Dot Music을 소개하거나 2차 활용하실 때에도 위 두 분에 대한 크레딧을 함께 남겨주시길 부탁드립니다.

## ✨ 이런 도구입니다

Dot Music은 **설치가 필요 없는 단일 HTML 파일**입니다.
서버도, 빌드도, 외부 오디오 라이브러리도 없이 **Web Audio API + Canvas**만으로 소리와 그림을 동시에 만들어냅니다.

- 🎨 **보이는 것이 들린다** — 화면 왼쪽의 원본과 오른쪽의 격자 애니메이션이 1:1로 대응합니다.
- 🎹 **악보를 몰라도 된다** — 음계(Scale)를 고르면 어떤 점을 찍어도 어울리는 음만 울립니다.
- 📱 **어디서나 된다** — PC·태블릿·스마트폰 브라우저에서 바로 실행되며, 터치로도 점을 찍을 수 있습니다.
- 🌏 **한국어 / English** — 우측 상단 번역 버튼으로 즉시 전환됩니다.

## 🕹️ 세 가지 모드

### 1. 🖼️ IMAGE — 그림 위에 작곡하기
이미지를 업로드한 뒤 **원하는 곳을 클릭(터치)하면 점(음표)** 이 찍힙니다.
스캔 라인이 격자를 훑고 지나가며 점을 하나씩 연주합니다.

- 점의 **세로 위치(행)** 가 음의 높이를 결정합니다. 위로 갈수록 높은 음, 아래로 갈수록 낮은 음.
- 점의 **가로 위치(열)** 가 연주되는 순서(박자)를 결정합니다.
- 재생 방향은 **→ / ← / ↓ / ↑ / ↘(대각선)** 5가지 중에서 고를 수 있습니다.

### 2. 🎬 VIDEO / GIF — 영상의 움직임이 곧 연주
동영상(mp4, webm)이나 GIF를 업로드하면, **프레임 간 픽셀 변화량을 실시간으로 감지**해 소리로 바꿉니다.
움직임이 큰 곳일수록 더 크게 울리며, 한 프레임당 변화가 가장 큰 상위 3개 지점이 동시에 연주됩니다.

### 3. 📷 WEBCAM — 내 몸짓이 악기가 되는 순간
카메라 접근을 허용하면 **거울처럼 좌우 반전된 화면**에서 내 움직임이 즉시 픽셀 아트와 음악으로 변환됩니다.
손을 흔들고 몸을 움직이는 것만으로 연주가 됩니다. 수업에서 가장 반응이 좋은 모드입니다.

## 🎛️ 조작 패널

| 컨트롤 | 설명 | 적용 모드 |
|---|---|---|
| **재생 방향 (Direction)** | 스캔 라인의 진행 방향 (→ ← ↓ ↑ ↘) | IMAGE |
| **속도 (Speed)** | 40 ~ 240 BPM. 16분음표 단위로 스캔 | IMAGE |
| **감도 (Sensitivity)** | 움직임 감지 민감도. 높을수록 작은 움직임도 소리로 | VIDEO / WEBCAM |
| **잔상 시간 (Trail Decay)** | 켜진 점이 사라지는 속도. 길수록 잔상이 오래 남음 | 전체 |
| **점 색상 (Dot Color)** | 격자에 찍히는 점의 색 | 전체 |
| **배경 색상 (Bg Color)** | 격자 배경색 (밝기에 따라 격자선 대비가 자동 조정) | 전체 |
| **신디사이저 (Synth)** | 음색 6종 선택 | 전체 |
| **음계 (Scale)** | 사용할 음계 8종 선택 | 전체 |

### 🎹 신디사이저 6종

| 이름 | 음색 | 합성 방식 |
|---|---|---|
| **NEIGE** *(기본값)* | 눈처럼 맑고 부드러운 소리 | Sine 파형 + 긴 릴리즈 |
| **PLUIE** | 빗방울처럼 톡톡 튀는 소리 | Triangle 파형 + 짧은 감쇠 (Pluck) |
| **ORAGE** | 폭풍처럼 굵고 거친 소리 | Sawtooth + 로우패스 필터 스윕 |
| **CLOCHE** | 종소리 | 실제 종의 **비조화 배음비**(1 : 2.756 : 5.404) 중첩 |
| **BOIS** | 마림바 같은 나무 타악기 | Triangle + 밴드패스 필터 |
| **CORDES** | 현악기의 보잉 질감 | Sawtooth + 로우패스, 느린 어택 |

모든 음색은 **2.5초 길이의 컨볼루션 리버브**를 거쳐 공간감을 갖습니다.

### 🎼 음계 8종

`Cm` · `Am` · `C Major` · `Minor Penta` · `Major Penta` · `Blues` · `Dorian` · `Mixolydian`

기준음은 **C3(130.81Hz)** 이며, 격자의 맨 아랫줄이 가장 낮은 음입니다.
행이 위로 올라갈수록 선택된 음계의 구성음을 따라 옥타브를 넘나들며 상승합니다.
→ **어떤 점을 찍어도 음계 안의 음만 울리기 때문에, 음악을 몰라도 불협화음이 나지 않습니다.**

## 📤 결과물 저장하기

### 🔴 REC — 연주 영상 녹화
원본 화면과 격자 애니메이션이 **나란히 배치된 1280×640 분할 화면 영상**을 소리와 함께 녹화합니다.
정지하면 `DotMusic_Performance.webm` 파일로 자동 저장됩니다.
*(Canvas `captureStream` + Web Audio `MediaStreamDestination`을 합성하여 MediaRecorder로 기록)*

### 📸 CAPTURE — 화면 캡쳐
현재 화면을 분할 이미지로 캡쳐합니다. **클립보드 복사** 또는 `DotMusic_Capture.jpg` **다운로드**를 선택할 수 있습니다.
캡쳐본에서는 잔상 때문에 흐려진 점들이 **100% 불투명으로 보정**되어, 작품으로 남기기 좋은 선명한 이미지가 만들어집니다.

### 📝 NOTE — 작곡 노트
캡쳐 이미지 아래에 **작곡가 이름과 곡 설명**을 적어 하나의 이미지로 저장합니다 (`DotMusic_CompositionNote.jpg`).
수업에서 학생들의 작품을 기록하고 전시할 때 유용합니다.

## 🎓 수업에서 활용하기

Dot Music은 **교육뮤지컬 수업 현장에서 쓰기 위해** 만들어졌습니다.

- **음악 × 미술 융합 수업** — 자신이 그린 그림 위에 점을 찍어 '그림이 들리는' 경험을 만듭니다.
- **신체 표현 활동** — 웹캠 모드에서 몸짓이 소리가 되는 즉흥 연주를 합니다. 모둠별 '움직임 합주'도 가능합니다.
- **음계 탐구** — 같은 점 배치에서 음계만 바꿔보며 장조·단조·블루스의 분위기 차이를 귀로 비교합니다.
- **작품 아카이빙** — 작곡 노트 기능으로 학생 결과물을 이름·설명과 함께 이미지로 남깁니다.

## 🛠️ 기술 정보

| 항목 | 내용 |
|---|---|
| **구조** | 의존성 없는 **단일 `index.html`** (HTML + CSS + Vanilla JS) |
| **오디오** | Web Audio API — 오실레이터·필터·컨볼루션 리버브 직접 구현 |
| **그래픽** | Canvas 2D — 소스 캔버스 / 격자 캔버스 / 녹화 캔버스 분리 |
| **움직임 감지** | 축소된 오프스크린 캔버스의 프레임 간 RGB 차분 비교 |
| **녹화** | MediaRecorder (VP9/VP8 + Opus, 미지원 시 자동 폴백) |
| **폰트** | Black Han Sans (제목) · Pretendard GOV (본문) |
| **아이콘** | Material Symbols Outlined |
| **배포** | GitHub Pages (`CNAME` → `dotmusic.chichiboo.link`) |

### 로컬에서 실행하기

```bash
git clone https://github.com/chichiboo123/dotmusic.git
cd dotmusic
```

`index.html`을 브라우저로 열기만 하면 됩니다. 다만 **웹캠·마이크·클립보드 기능은 보안 컨텍스트(HTTPS 또는 localhost)** 를 요구하므로, 로컬 서버로 여는 것을 권장합니다.

```bash
python3 -m http.server 8000
# → http://localhost:8000 접속
```

### 권장 브라우저
최신 **Chrome / Edge**에서 가장 안정적으로 동작합니다.
Safari와 Firefox에서도 재생은 가능하지만, 녹화 코덱과 클립보드 이미지 복사 지원 범위가 다를 수 있습니다.
